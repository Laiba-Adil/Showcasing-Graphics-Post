

# 🖼️ Social Media Post Gallery (HTML Only)

This project is a simple **HTML-only gallery** to display a collection of social media posts in a structured layout. It uses only pure HTML — **no CSS or JavaScript** — making it an ideal example for beginners learning basic HTML elements like tables, images, and text formatting.

## 📌 Project Highlights

- ✅ Created using **only HTML** (no external CSS or styling libraries)
- 🖼️ Displays **9 social media post images** in a 3x3 grid
- 📐 Fixed image dimensions (`400px x 350px`) for uniformity
- 📁 Table layout used to arrange the images neatly
- 📍 Page headings centered and styled using the `<font>` tag and heading elements

## 🛠️ Technologies Used

- HTML5 (legacy `<font>` tag used for demonstration purposes)

## 💡 Learning Purpose

This project is best suited for:

- Practicing table layouts in HTML
- Understanding how to structure content with basic HTML elements
- Beginners who are just starting with web development
